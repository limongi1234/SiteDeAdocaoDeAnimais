# Site de Adoção de Animais 🐾

Website de **adoção de animais**, desenvolvido como **trabalho de front-end** com **HTML, CSS e Bootstrap**. Apresenta uma interface para divulgação de animais disponíveis para adoção.

## ✨ Características

- Layout responsivo com **Bootstrap 3**
- Barra de navegação e seções de conteúdo
- Estilização customizada em `css.css`
